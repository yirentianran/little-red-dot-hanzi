来源优先级为：教材附录的字、分类、分组和顺序最高；同版教材目录及课文页决定课名和语境；教材课文注音与辅助资料只用于交叉核对拼音。辅助资料与附录冲突时一律以附录及课文语境为准。

`docs/curriculum-readings.tsv` 是逐条对照教材附录与课文语境人工核对的全量读音审计基准。它按 `data/curriculum.json` 的 section 与组别顺序列出全部 521 条记录，保留 `character`、`pinyin`、`audio` 和计数口径，供评审者直接 diff；测试逐行比较 TSV 与 JSON，任一条目的分组、顺序、拼音、音频 id 或 `counted: false` 语义漂移都会定位到具体行。

本数据对应用户封面的 2019 审定版后续印次。该印次目录与课文第 6 课为《夜间飞行的秘密》，不是初印目录中的《蝙蝠和雷达》。本次拒绝使用 2024 年 8 月修订版的目录、生字或注音；版本判断以封面、版权页、ISBN、目录和附录共同完成，不能只凭网页标题。

- 单元 8 个；编号课文 27 篇；语文园地识字组 4 个；合计 31 个 section。

- 写字表 250 条，且写字表内 250 个字均唯一。
- 识字表与写字表合并后共有 428 个唯一汉字。
- 全量读音审计 TSV 共 521 个数据行，由 271 条识字显示记录和 250 条写字记录组成。

保留 271 条显示记录而不是删除蓝色字，才能同时忠实表达附录版面、课文语境读音和附录的“共 250 个生字”统计口径。

## 多音字与语境读音

附录以蓝色标出的 21 条多音字复习项已逐页按颜色复核，并全部标记 `counted: false`：

- 第 1 课：薄 `bó`（薄雾）。
- 第 6 课：系 `jì`（系着铃铛）。
- 第 8 课：雀 `qiǎo`（家雀儿）。
- 第 9 课：降 `xiáng`（投降）；写字表同样采用 `xiáng`，不是 `jiàng`。
- 第 10 课：曲 `qū`（弯曲）。
- 第 13 课：少 `shào`（少女）。
- 第 14 课：还 `huán`（归还）、脏 `zàng`（肝脏）。
- 第 17 课：相 `xiàng`（相片）。
- 第 18 课：吁 `yū`（吁哩哩哩）。
- 第 19 课：露 `lòu`（露脸）、角 `jué`（角色）、啊 `ā`、哄 `hōng`（哄堂大笑）、唉 `āi`。
- 第 20 课：钉 `dīng`（铁钉）。
- 第 21 课：将 `jiàng`（将领）。
- 第 23 课：宁 `nìng`（宁可）、要 `yāo`（要求）。
- 第 27 课：扎 `zhā`（扎针）、纪 `jǐ`（纪昌）；第 7 课写字表“世纪”的纪另按语境为 `jì`。

其他需要按课文语境而不能只查单字默认音的记录也已复核：苔 `tái`、屏 `píng`、占 `zhàn`、恶 `è`、混 `hùn`、呵 `hē`、殷 `yīn`、迫 `pò`、侯 `hóu`；写字表中的熟 `shú`、曾 `céng`、横 `héng`、核 `hé`、任 `rèn`、较 `jiào`、累 `lèi`、血 `xuè`、奔 `bēn`、著 `zhù`、量 `liàng`、颤 `chàn`、俩 `liǎ`、旋 `xuán`、塞 `sài` 均按课文词语确定。尤其第 12 课“血液”的血为 `xuè`，不是辅助网站常见的误注 `xué`。

拼音统一保存为 NFC 预组字符。音频 id 由拼音机械转换为小写编号式读音：去掉声调符号、附加 1-4 调号，轻声才使用 5；`ü` 转为 `v`。课程数据阶段只审计了音频 id 的文本映射；Task 4 现已导入并完成上述机器验证，但音频人工听检仍未完成。

## 语文园地建模

附录在第 2、4、6、8 单元各列出一组“语文园地”识字内容。它们不是编号课文，但属于识字表的正式分组，因此分别建模为 `garden-2`、`garden-4`、`garden-6`、`garden-8`，使用 `kind: "garden"`，不设置数字 `number`，并保留空的 `write` 数组。这样既不伪造课号，也不会遗漏附录中的正式识字条目。

## 离线发音资源

课程 521 条学习记录共引用 335 个唯一读音。对应的 335 个本地 MP3 来自
`hugolpz/audio-cmn` 仓库固定 commit
`ff9ed3d0c631195bd2c06f39450f3264c7124040` 的 `64k/syllabs` 子集，采用
CC BY-SA 3.0 许可；作者与说话人署名、官方法律文本来源及改名规则见
`assets/audio/THIRD_PARTY_NOTICES.md`。全部文件合计 3,198,006 个字节。

同步程序对每个文件执行了以下机器检查：

- 使用 `ffprobe` 以 JSON 读取媒体结构，确认音频流是单声道 MP3。
- 核对 ID3 中的 `SWAC_TEXT` 与上游读音标签一致，核对
  `SWAC_COLL_LICENSE=CC-BY-SA-3.0`，并确认作者与版权标签存在。
- 使用 `ffmpeg` 将整个音频流解码到空输出，排除只能读取文件头但无法完整解码的文件。
- 记录原始字节数和 SHA-256；本地 MP3 只改文件名，不转码、不重写 ID3，
  `manifest.json` 中的 `metadataVerified: true` 只表示这些机器检查通过。

运行 `npm run verify:audio` 可在无网络环境中重新读取当前 manifest，并复算精确
文件集合、字节数和 SHA-256，同时再次执行上述 ffprobe、完整 ffmpeg 解码和 ID3
元数据检查。

本地 `ju4.mp3` 对应上游 `cmn-jv4.mp3`，其源标签为 `jv4`；其余 id 与源标签
相同。需要重点人工确认的课内多音读音 id 为：`ji4`、`qiao3`、`shao4`、
`huan2`、`xiang4`、`lou4`、`jue2`、`ning4`、`yao1`、`ji3`、`xiang2`、
`xue4`。
