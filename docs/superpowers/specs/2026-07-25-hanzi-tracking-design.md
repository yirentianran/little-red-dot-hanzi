# 人教版四年级上册汉字追踪学习页设计

日期：2026-07-25

## 1. 项目目标

构建一个可直接双击 `index.html` 使用的静态网页，帮助儿童学习人教版《义务教育教科书·语文 四年级上册》的生字读音与规范笔顺，并通过沿笔画移动的红点练习视觉追踪。

教材范围固定为用户提供封面所对应的版本：人民教育出版社，教育部审定 2019，四年级上册。首期收录该册各课“会认”和“会写”的全部生字，并保留教材中的单元、课文顺序和分类。

## 2. 设计原则

- 完全离线：运行时不访问 CDN、接口、在线字体或语音服务。
- 直接打开：支持通过 `file://` 打开，不要求安装依赖或启动本地服务器。
- 儿童优先：汉字是主要视觉焦点，控件适合触屏，页面文字简洁。
- 数据准确：教材分类、拼音、笔画轮廓、笔顺轨迹和发音在交付前完成校验。
- 易于维护：教材目录与汉字资源分层，重复出现的汉字只保存一份笔画数据。

## 3. 范围

### 3.1 首期包含

- 按单元和课文浏览全册内容。
- 按“会认”和“会写”查看每课生字。
- 显示汉字、带声调拼音、笔画数和当前学习进度。
- 点击按钮播放本地普通话发音。
- 自动循环演示规范笔顺，红点沿当前笔画前端移动。
- 暂停、重播、上一笔、下一笔，以及慢速、适中、快速三档速度。
- 上一个字、下一个字和返回课文。
- 在浏览器本地记住最近一次学习位置。
- 适配手机、平板和电脑。

### 3.2 首期不包含

- 字库导入、导出或可视化编辑器。
- 用户账号、云同步和学习数据统计。
- 手写识别、触摸描红评分或摄像头追踪。
- 人教版四年级上册以外的教材。
- 自动播放发音。

## 4. 信息架构

应用是一个单页静态学习工具，包含三个视图。

### 4.1 全册目录

- 顶部显示“语文四年级上册”和教材版本。
- 内容按单元分组，每个单元列出课序、课名和生字数量。
- 点击课文进入该课生字视图。

### 4.2 课文生字

- 显示单元、课序和课名。
- 使用“会写 / 会认”分段控件切换教材分类。
- 每个生字以“汉字 + 拼音”方格展示。
- 点击任一生字进入单字追踪视图。
- 提供“从第一个字开始学习”命令。

“会认”表示教材要求儿童认读的汉字，界面优先展示汉字、拼音和发音；“会写”表示教材要求规范书写的汉字，进入后默认自动播放笔顺。两类汉字都具备完整的拼音、发音和笔顺功能。

### 4.3 单字追踪

- 桌面端采用用户选择的“小课堂”左右布局：左侧为米字格动画，右侧为拼音、发音、笔画进度、模式和速度。
- 窄屏改为上下布局，米字格在上，信息与控件在下。
- 顶部提供返回课文和“当前字 / 本组总字数”。
- 底部提供上一个字和下一个字。
- 返回课文时保留当前“会认 / 会写”分类和生字位置。

页面状态同步到 URL hash，使浏览器前进、后退和刷新后仍能恢复相同课文、分类与汉字。最近学习位置同时写入 `localStorage`，下次打开首页时可继续学习。

## 5. 视觉设计

采用用户选择的“明快练习”方向。

- 页面基调：浅天蓝，用于区分学习环境与白色内容区域。
- 信息强调：明黄，用于拼音和学习状态区域。
- 动画焦点：朱红，仅用于移动红点和错误提示，避免红色泛滥。
- 文字与主按钮：深蓝和中蓝，保证对比度。
- 汉字：近黑色；未完成笔画使用低对比浅灰蓝。
- 组件边角不超过 8px，不使用装饰性渐变、光斑或卡片嵌套。
- 米字格使用稳定的正方形比例，动态内容不得改变其尺寸。
- 交互目标最小为 44 × 44 CSS 像素，文字不得依靠视口宽度缩放。

## 6. 笔顺动画

### 6.1 SVG 数据

每个汉字包含两组等长数据：

- `strokes`：每一笔的封闭 SVG 轮廓路径。
- `medians`：与该笔对应的中心轨迹点列。

首期笔画几何采用 Hanzi Writer Data 兼容数据快照，其字形源自 Make Me a Hanzi 数据集。项目只提取本册实际使用的汉字，并随交付文件保留上游来源、数据版本和许可说明。所有字符使用统一坐标系。渲染时将中心点列转换为 SVG path，并按显示尺寸缩放。轮廓决定规范字形，中心轨迹只用于揭示当前笔画和计算红点位置，不作为可见辅助线。

### 6.2 绘制方式

- 未完成笔画以浅灰蓝轮廓显示。
- 已完成笔画完整显示为近黑色。
- 当前笔画的轮廓作为裁剪区域；沿中心轨迹逐步增长的粗线揭示轮廓，从而形成自然的书写效果。
- 红点通过中心轨迹的总长度和 `getPointAtLength()` 计算当前位置，与笔画揭示进度共用同一时间值。
- 每笔时长根据轨迹长度计算，并限制最短与最长值，避免短点过慢或长折过快。

### 6.3 播放状态

动画控制器使用明确状态：`idle`、`playing`、`paused`、`between-strokes` 和 `completed`。

- 进入“会写”汉字后，从第一笔开始自动循环。
- 每笔结束后短暂停顿；整字结束后停留更长时间，再重新开始。
- 暂停保留当前笔画与红点位置，继续时从原位置恢复。
- “重播”立即回到第一笔并自动播放。
- “上一笔”切换到前一笔，保留此前笔画并播放该笔；第一笔时按钮禁用。
- “下一笔”完成当前笔之前的所有笔画并播放下一笔；最后一笔时按钮禁用。
- 手动使用上一笔或下一笔后进入逐笔模式，当前笔播放完成即停住。
- 切换汉字后恢复该分类的默认模式：会写自动播放，会认静止展示完整汉字，用户点击播放后才开始动画。
- 速度为慢速、适中和快速三档，默认适中；更改速度不重置当前进度。

动画由 `requestAnimationFrame` 和 `performance.now()` 驱动，不使用大量 CSS 定时器。页面进入后台时暂停计时，返回前台后从原位置继续，避免跳笔。

## 7. 发音

- 每个教材读音关联一个本地普通话音频文件。
- 音频为离线合成语音，按教材语境确定读音并逐项校验；多音字不得依赖浏览器自行选择读音。
- 只有用户点击发音按钮时才播放，页面进入或切换汉字时不自动发声。
- 连续点击时从头重播当前发音，并停止上一段音频。
- 音频文件在交付前完成可解码检查；运行时加载失败则禁用该字的发音按钮并显示短提示，不影响笔顺功能。

## 8. 数据模型

原始可维护数据使用 JSON，分为教材目录和汉字资源。

教材目录的逻辑结构：

```json
{
  "schemaVersion": 1,
  "book": {
    "publisher": "人民教育出版社",
    "approvalYear": 2019,
    "grade": 4,
    "volume": "上册"
  },
  "units": [
    {
      "id": "unit-1",
      "title": "第一单元",
      "lessons": [
        {
          "id": "lesson-1",
          "number": 1,
          "title": "观潮",
          "recognize": [{ "character": "盐", "pinyin": "yán", "audio": "yan2" }],
          "write": [{ "character": "潮", "pinyin": "cháo", "audio": "chao2" }]
        }
      ]
    }
  ]
}
```

汉字资源是一个以单个汉字为键的 JSON 对象。每条记录包含整数 `strokeCount`、含完整 SVG path 字符串的 `strokes` 数组，以及由二维坐标点列组成的 `medians` 数组。三者的笔画数量必须相等；数组顺序就是规范笔顺。

教材条目保存课内读音，汉字资源只保存与读音无关的字形数据。同一个汉字在不同课文出现时复用字形；若课内读音不同，则教材条目分别引用不同音频。

## 9. 数据生成与交付格式

仓库保留经过校对的原始 JSON。构建脚本执行以下步骤：

1. 读取教材目录和汉字资源。
2. 校验标识符、单元和课序、重复项、汉字长度及带声调拼音格式。
3. 确认每个教材汉字都存在资源记录。
4. 确认 `strokeCount`、`strokes.length` 和 `medians.length` 完全一致，且每条轨迹至少有两个有效点。
5. 确认每个教材读音对应的本地音频存在并可解码。
6. 生成一个经典脚本格式的运行时数据文件，例如 `data/library-data.js`。

运行时不通过 `fetch()` 读取 JSON，因为部分浏览器会阻止 `file://` 页面读取相邻文件。`index.html` 使用普通 `<script src>` 顺序加载运行时数据和应用脚本，从而保持直接打开兼容性。原始 JSON 仍作为可审查和维护的事实来源。

## 10. 组件与文件边界

建议文件结构：

```text
index.html
styles.css
assets/
  audio/
data/
  curriculum.json
  characters.json
  library-data.js
js/
  animation-controller.js
  audio-controller.js
  data-store.js
  router.js
  svg-renderer.js
  views.js
  app.js
scripts/
  build-library.mjs
  validate-library.mjs
tests/
```

- `data-store`：查询教材、课文和汉字资源，不接触 DOM。
- `router`：解析和更新 URL hash，恢复合法页面状态。
- `svg-renderer`：创建米字格、笔画、轨迹裁剪和红点。
- `animation-controller`：管理播放状态和时间，不负责页面导航。
- `audio-controller`：保证一次只播放一个本地发音。
- `views`：渲染目录、课文和单字视图，并把用户命令转给控制器。
- `app`：初始化数据、路由、视图和本地学习位置。

所有运行时 JavaScript 使用浏览器可直接加载的经典脚本或构建后合并脚本，不依赖原生 ES module 的 `file://` 行为。

## 11. 错误处理

- 数据生成时发现缺字、缺轨迹、笔画数量不一致、无效拼音或缺音频，命令以非零状态退出并列出课文和汉字。
- URL 指向不存在的课文、分类或汉字时，回退到全册目录，不显示空白页。
- 单个汉字的运行时笔画数据意外损坏时，显示“该字数据待补充”，保留拼音、发音和前后字导航。
- 音频加载失败时禁用发音按钮，笔顺学习继续可用。
- `localStorage` 不可用时仅关闭继续学习功能，不影响其他操作。
- 对快速连续点击进行状态串行化：切换汉字时停止旧动画和旧音频，旧回调不得修改新页面。

## 12. 无障碍与儿童使用

- 所有按钮使用原生 `button`，具有可见焦点和准确的中文可访问名称。
- 分段控件使用可访问的标签与选中状态，不仅依赖颜色表达“会认 / 会写”。
- 图标按钮提供工具提示和屏幕阅读器标签；清晰命令可使用图标加短文字。
- 红点具有白色描边和外圈，在浅色与深色笔画上都可见。
- 状态文本通过非打断式 live region 宣布“第几笔”和错误提示，但动画每帧不触发朗读。
- 键盘可操作所有控件；焦点顺序与视觉顺序一致。
- 用户系统设置减少动态效果时不自动循环，仍可手动逐笔播放。

## 13. 测试与验收

### 13.1 数据测试

- 教材目录、课名、课序和每课生字逐项对照 2019 审定版。
- “会认 / 会写”分类准确，无漏字、错误读音，且同一课同一分类内没有意外重复；教材要求的跨课或跨分类复用保留原样。
- 每个教材汉字都有可解析轮廓、等量中心轨迹和有效笔画数。
- 每个教材读音都有可解码的本地音频。
- 构建输出可重复生成，且不包含网络 URL。

### 13.2 单元测试

- 轨迹长度和时间进度到 SVG 点位的换算。
- 播放、暂停、继续、逐笔、重播和循环状态转换。
- 速度切换时保持当前相对进度。
- 路由解析、非法 hash 回退和最近位置恢复。
- 快速切换汉字时旧动画与音频正确销毁。

### 13.3 浏览器流程测试

- 通过 `file://` 打开 `index.html`，在阻断网络的情况下完成目录、课文和单字学习流程。
- 验证自动循环、暂停、上一笔、下一笔、重播、三档速度、发音和前后字。
- 验证浏览器前进、后退、刷新和重新打开后的状态。
- 检查窄手机、手机横屏、平板和桌面尺寸，页面无重叠、溢出或动态位移。
- 检查减少动态效果设置下不会自动循环。

### 13.4 人工视觉与内容抽查

- 对目录页、课文页和单字页进行桌面与移动端截图检查。
- 抽查简单字、长横竖字、折笔字、复杂字和左右结构字。
- 人工确认红点从正确起点出发，沿转折移动，并在正确终点结束。
- 人工试听普通读音和多音字读音。

## 14. 交付标准

- 用户无需安装软件即可打开学习页。
- 全册目标生字可按教材单元、课文和“会认 / 会写”访问。
- 所有目标生字均可显示拼音、播放本地发音并演示规范笔顺。
- 页面在完全断网时无功能降级，且不产生网络请求。
- 手机、平板和电脑上的核心工作流均通过自动检查与人工视觉验收。
